**OLLYCONN LLC** is a New York software engineering and AI consulting company, run by John Connolly.

We help businesses design, build and ship production software, with a focus on applied AI: LLM-backed applications, agentic developer tooling, and the platform work underneath them.

## Services

- **Architecture and integration engineering.** System design, API and data integrations, cloud infrastructure (AWS, Azure), and the plumbing that connects new software to existing systems.
- **Applied AI and LLM systems.** Retrieval-augmented generation, MCP servers, agent workflows, evaluation, and putting guardrails around model output in production.
- **AI-assisted delivery.** Setting up teams to ship with coding agents safely: review gates, verification, tooling and cost controls.
- **Code review and technical leadership.** Independent review of codebases and pull requests, and hands-on guidance for engineering teams.

## How we work

Engagements are scoped in writing, delivered remotely, and billed hourly against invoices. We work asynchronously by default, with a single point of contact on the client side.
